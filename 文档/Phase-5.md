# Phase 5 — 所有权与内存模型

Phase 5 开始建立玄言的内存安全基础。

## 核心模型

玄言资源具有明确的所有权状态：

拥有
→ 借用
→ 可变借用
→ 移动
→ 已释放

## 设计目标

玄言不依赖传统垃圾回收机制作为主要内存安全模型。

编译器负责在程序执行前验证：

- 资源是否有效
- 资源是否已经移动
- 是否存在非法重复移动
- 共享借用与可变借用是否冲突
- 生命周期是否满足使用要求

## 借用模型

共享借用：

&资源

可变借用：

&可变资源

基本规则：

多个共享借用可以同时存在。

可变借用必须具有独占访问权。

共享借用存在时，不允许新的可变借用。

## 生命周期

当前阶段建立生命周期模型：

- 临时
- 当前作用域
- 显式生命周期
- 静态

完整生命周期推导将在后续阶段实现。
