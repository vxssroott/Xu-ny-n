# Phase 6 — 中间表示与代码生成

Phase 6 建立玄言的编译器后端边界。

## 编译链

源码
→ 词法分析
→ Token
→ 语法分析
→ AST
→ 类型系统
→ 所有权系统
→ IR
→ 代码生成

## 中间表示

玄言 IR 当前包含：

- 模块
- 函数
- 基本块
- 参数
- 局部资源
- 加载
- 存储
- 调用
- 返回
- 基础类型
- 常量值

## 后端

当前实现一个目标无关的文本后端。

它不是最终机器码。

它的作用是验证：

> AST / Semantic Model → IR → Backend

这一编译边界是否成立。
